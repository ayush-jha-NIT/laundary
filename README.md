# UJALA Dry Clean

Production website for UJALA Dry Clean, Prayagraj.

## Current implementation

Part 0 foundation includes:

- Next.js App Router + TypeScript
- Tailwind CSS foundation
- UJALA brand tokens
- Central business configuration
- Seed service catalogue without pricing
- Routes for Home, Services, About Us, How It Works and Contact
- UJALA logo asset
- Basic metadata and 404 page
- Production scripts for build, lint and type checking
